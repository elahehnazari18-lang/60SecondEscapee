60 SECOND ESCAPE — نسخه پیشرفته MVP

این نسخه علاوه بر نسخه قبلی دارد:
- منوی شروع
- دکمه Pause/Resume
- افزایش سختی و سرعت
- Combo برای جمع‌آوری سکه
- Power-up سپر
- Power-up کندکننده زمان
- امتیازدهی زنجیره‌ای
- نور روی بازیکن
- واکنش به pause شدن اپلیکیشن
- رابط کاربری کامل‌تر

ساخت APK در ویندوز/مک:
1. Unity Hub را نصب کن.
2. Unity 2022.3 LTS را با Android Build Support نصب کن.
3. SDK & NDK Tools و OpenJDK را نیز از Unity Hub نصب کن.
4. ZIP را Extract کن و پوشه 60SecondEscape_Advanced_UnityProject را در Unity Hub با Add/Open باز کن.
5. از منوی Unity گزینه 60 Second Escape > Setup Game Scene را بزن.
6. Play را بزن و تست کن.
7. File > Build Settings > Android > Switch Platform.
8. سپس 60 Second Escape > Build Android APK.
9. خروجی: Builds/60SecondEscape.apk

نصب مستقیم:
فایل APK ساخته‌شده را به گوشی Android منتقل کن و باز کن. اگر Android اجازه نصب از منبع موردنظر را خواست، برای همان برنامه مدیریت فایل/مرورگر اجازه Install unknown apps را فعال کن.
برای انتشار عمومی در Google Play بهتر است نسخه Release را با Keystore امضا کنی و برای Google Play معمولاً AAB بسازی؛ APK برای نصب مستقیم روی گوشی مناسب است.

کنترل:
موبایل: Swipe چپ/راست.
PC: A/D یا Left/Right.

این پروژه یک MVP قابل Build است، نه یک بازی تجاری کامل. برای انتشار حرفه‌ای بهتر است بعداً Asset، صدا، موسیقی، منوی تنظیمات، ذخیره رکورد و فروشگاه اسکین اضافه شود.
